# Data: SMS Spam Collection v.1

The raw data file is not stored in this repository.

## Source
UCI Machine Learning Repository:
https://archive.ics.uci.edu/dataset/228/sms+spam+collection
5,574 English SMS messages labeled ham (4,827) or spam (747).

## How to get it
1. Download the zip from the page above and extract it.
2. Create the folder `data/raw/` if it does not exist.
3. Copy the file `SMSSpamCollection` into `data/raw/`.

## Citation
Almeida, T.A., Gomez Hidalgo, J.M., Yamakami, A. Contributions to the study of SMS
Spam Filtering: New Collection and Results. Proceedings of the 2011 ACM Symposium on
Document Engineering (DocEng'11), Mountain View, CA, USA, 2011.
Dataset page: http://www.dt.fee.unicamp.br/~tiago/smsspamcollection/
