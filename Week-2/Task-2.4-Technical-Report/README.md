# Task 2.4 - Deep Learning Technical Report

## Objective
Compare PyTorch model performance across Week 2 experiments and summarize findings
in a short written report.

## Tools Used
- Python (reportlab, for PDF generation)
- Findings drawn from Tasks 2.1, 2.2, and 2.3

## Work Completed
1. Synthesized results across the feed-forward network (Task 2.1), CNN classifier
   (Task 2.2), and hyperparameter experiments (Task 2.3)
2. Wrote a problem statement and architecture summary for all three tasks
3. Built comparison tables covering model performance and hyperparameter effects
4. Summarized key findings on learning rate, optimizer, batch size, and epoch count
5. Assessed generalization behavior (underfitting/overfitting) across all three tasks
6. Documented limitations and realistic next steps

## Deliverables
- Technical report (PDF): `Rakshitha_Week2_Technical_Report.pdf` (2 pages)

## Key Learnings
- How to synthesize results from multiple separate experiments into one coherent
  narrative for a reader who has not seen the underlying notebooks
- The importance of stating limitations (e.g., single-seed experiments) alongside
  results, rather than presenting numbers as fully conclusive
- How to distinguish a genuine hyperparameter effect from one that is confounded
  with another setting (e.g., SGD underperforming specifically at a fixed learning
  rate, not necessarily in general)
