# Task 1.3 - Math for ML

## Objective
Practice practical mathematics used in ML: descriptive statistics, 
probability, linear algebra, and basic calculus, with notes connecting 
each concept to real ML applications.

## Tools Used
- Python 3.11.9
- NumPy
- Jupyter Notebook

## Work Completed
1. Descriptive statistics: mean, median, variance, standard deviation
2. Covariance and correlation, including a caution against correlation-causation confusion
3. Probability: basic events, conditional probability, independence check, expected value
4. Linear algebra: vectors, matrices, dot products, matrix multiplication
5. Calculus: derivatives and a working gradient descent loop

## Deliverables
- `math_for_ml.ipynb` - worked solutions with ML-connection notes

## Key Learnings
- Standardization in ML preprocessing is built directly on mean/std dev
- Correlation never proves causation - important when interpreting features
- Neural network layers are literally matrix multiplications (dot products)
- Gradient descent is just repeated derivative calculations moving toward a minimum
