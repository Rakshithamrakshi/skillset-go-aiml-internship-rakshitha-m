# Task 1.1 - Python Fundamentals

## Objective
Practice core Python fundamentals including variables, data types, 
conditions, loops, functions, lists, dictionaries, file handling, 
exception handling, and object-oriented programming (OOP).

## Tools Used
- Python 3.11.9
- VS Code

## Work Completed
1. Variables, data types, and basic input/output
2. Conditions (if/elif/else) and loops (for/while) - grade calculator
3. Functions - reusable average/grade calculation logic
4. Lists and dictionaries - student records with topper detection
5. File handling (read/write) and exception handling (FileNotFoundError, ValueError)
6. Object-oriented programming - a Student class with methods

## Deliverables
- `src/01_variables_datatypes.py`
- `src/02_grade_calculator.py`
- `src/03_functions.py`
- `src/04_lists_dictionaries.py`
- `src/05_file_handling_exceptions.py`
- `src/06_oop_classes.py`
- Screenshots of each script's output in `screenshots/`

## Key Learnings
- How Python evaluates conditions top-to-bottom in if/elif/else chains
- Why functions reduce repeated code (DRY principle)
- How to safely handle missing files and invalid input using try/except
- How classes bundle data (attributes) and behavior (methods) together
